# Fase 1 - demo vendible vehicular

Contexto: se toma como nicho inicial lavadero, detailing y lubricentro, bajo el
posicionamiento "gestion para negocios vehiculares".

Alcance implementado:

- La primera experiencia comercial puede usar datos demo precargados.
- El negocio real queda vacio y guiado desde el dashboard con pasos de alta.
- La salida comercial prioriza demo por WhatsApp, landing publica, Instagram y referidos.
- El checklist muestra Agenda, turnera publica, WhatsApp, caja y dashboard.
- Inventario avanzado y consola interna quedan fuera de la muestra principal.

Superficies:

- Dashboard: panel "Salida comercial" con avance y seis pasos navegables.
- Defaults de negocio nuevo: sectores lavadero, detailing y lubricentro.
- Seed demo: servicios de lubricentro sin activar inventario avanzado.
- Metadata y copys: "gestion operativa para negocios vehiculares".
